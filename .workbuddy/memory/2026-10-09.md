## 数据库设计 V1（极简方案）
- 3 张表：`<班座>_user`（人员档案+登录）、`<班座>_material`（物料）、`<班座>_inout`（进出仓，1 表方案，io_type 区分进/出）。
- 3 个存储过程：sp_in / sp_out / sp_inout_multi；多物料通过 JSON 数组入参，事务内 INSERT...SELECT + UPDATE...JOIN 一次完成。
- 异常处理：SQLSTATE '45000' + SIGNAL 抛出，EXIT HANDLER 自动 ROLLBACK。
- 并发安全：sp_out 使用 SELECT...FOR UPDATE 行级锁。
